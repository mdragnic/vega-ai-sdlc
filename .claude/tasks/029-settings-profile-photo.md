## Goal
The upload box on Settings' Account tab (111) becomes a control: it opens a file picker, a chosen file is checked at once with the shared photo rule (a refused one shows its error and is not kept), a valid one shows as a local preview with "Clear" (#128 a) and counts as a change (#127 b), "Save changes" sends it as the `photo` part of task 028's one `PATCH /api/profile` (#76), the backend checks it by its first bytes, stores it as uploaded under a random name with the row's path, type and time, and serves it back only to its owner through `GET /api/profile/photo`; the box and the sidebar avatar then show it, and without one the avatar keeps the initials (US-18 criteria 6, 8's photo rule, 10, 12 and 13).
