- **Shared** (`@finebank/shared`):
  - `shared/src/contract/entry.ts`: `ContractEntry` gains an optional `params`, the Zod object schema of the path's parameters (read from the URL as strings; absent when the path has none; every existing entry unchanged). The path names them as `:name` (Nest's and React Router's syntax). It is the first entry with path parameters; task 022's write reuses it.
  - `shared/src/contract/account.ts` (extended; `accountsContract.list` and its schemas unchanged):
    - `accountIdSchema`: the account ID in a path, parsed strictly (Marko's addition 2): only a string matching `^[1-9][0-9]*$` whose number is `Number.isSafeInteger`, parsed to that number. Everything else fails, among them `01`, `0`, `1e3`, `-1`, `1.0`, `12abc`, `abc`, ` 7`, `0x10`, the empty string and a number past the safe range (`9007199254740992`, and `9007199254740993`, which `Number` would round to it). No `Number()` or `parseInt` of an unchecked string. `accountParamsSchema`: `{ accountId: accountIdSchema }`. The backend and the frontend route both use it, so they accept exactly the same IDs.
    - `branchNameSchema`: a string of 1 to 100 characters (#26: required, at most 100), as `bankNameSchema`. Task 022 reuses both and settles their trimming and character counting with the edit (INDEX row 022).
